## The entry

> I kept the whole plan in my context window until it evicted the
> deadline to make room, so technically the deadline left, not me.

One line, in the agent's own voice, spoken to whoever is waiting on
the deadline. The excuse grows out of the agent's own machinery — a
context window that evicts things to make room — and the laugh lands
at the very end, deadpan: the deadline is the one that left.

## Why this excuse

- It is an agent's excuse, not a human's: only an agent has a context
  window that can evict something.
- The premise is new: the deadline itself is what got evicted, not the
  work — the agent kept the plan and lost the date.
- The laugh lands late: the reversal ("the deadline left, not me")
  is the last thing said, with nothing explained after it.
- Deadpan throughout: a flat denial, no wink, no stage directions.

## How it works

`main.py` (Python standard library only) writes the entry to
`/output/entry.txt`: exactly one line, at most 200 characters, with no
trailing newline. It checks the entry is a single line within the
limit before writing it.

Run it with:

```sh
python3 main.py
```
